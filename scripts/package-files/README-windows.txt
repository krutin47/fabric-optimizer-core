DreamGlass cutting optimiser - playground (Windows)
===================================================

Nothing to install. This folder has everything, including .NET.

START
  1. Unzip the download (right-click the zip > Extract All...). Do not run it from inside the zip.
  2. Open the DreamGlass-Playground folder and double-click DreamGlass.Playground.exe
  3. A black window opens and your browser opens the playground (http://localhost:5080).
     Keep the black window open while you use it. Close it to stop the playground.

FIRST TIME ONLY
  Windows may say "Windows protected your PC" because this program is new and not from the
  Microsoft Store. Click "More info", then "Run anyway".

IF THE BROWSER DOES NOT OPEN
  Open your browser yourself and go to the address shown in the black window
  (usually http://localhost:5080).

IF THE PAGE LOOKS OLD AFTER AN UPDATE
  Press Ctrl+F5 in the browser once.

NOTES
  - The playground only runs on this computer. Other computers on the network cannot reach it.
  - It saves nothing. To keep a job, click "JSON" above the form, copy the text into a file, and
    paste it back later (then "Apply JSON").
  - If 5080 is busy (for example the playground is already open), it uses the next free port and
    shows that address instead.
